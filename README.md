## الملفات
- `index.html` — البرنامج نفسه
- `data.json` — بيانات الجداول (ده الملف اللي بتغيّره لما الجداول تتغير)
- `manifest.webmanifest` و `sw.js` و `icons/` — علشان يتثبت كتطبيق على الموبايل
- `LICENSE` — حقوق الملكية

## الرفع على GitHub Pages
1. أنشئ مستودع جديد (Repository) على GitHub، واكتب له اسم مثل `imam-malik-timetable`.
2. ارفع كل الملفات والمجلدات دي بنفس الأسماء (Add file ← Upload files).
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. استنى دقيقة وهيظهر لك الرابط: `https://اسمك.github.io/imam-malik-timetable/`
5. افتح الرابط من Chrome في الموبايل ← القائمة (⋮) ← "تثبيت التطبيق" أو "Add to Home screen".

## تحديث الجداول
1. ابعت ملف الجداول الجديد (PDF) لـ Claude، وهيرجّع لك `data.json` جديد.
2. على GitHub افتح `data.json` ← Upload/Replace بالملف الجديد ← Commit.
3. المعلمين يضغطوا 🔄 في البرنامج، أو يتحدّث لوحده أول ما يفتحوه وفيه إنترنت.
